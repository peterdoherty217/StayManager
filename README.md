# StayManager

StayManager is a Java and MySQL property booking management system developed as a personal Computer Science project.

## Features

- Create bookings
- View saved bookings
- Search bookings by ID
- Cancel bookings
- Add and manage multiple properties
- Store guests and bookings in MySQL
- Input validation
- Revenue reporting
- Prevent overlapping bookings

## Technologies Used

- Java
- MySQL
- JDBC
- IntelliJ IDEA
- Git
- GitHub

## Database Structure

The application uses three main tables:

- Guest
- Property
- Booking

Bookings are linked to guests and properties using foreign keys.
